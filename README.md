Text-based card game based on real life Uno game.

Known issues:
1. There have been two cases of one of the active player's card not being printed among the cards that could be selected. Although the error has not occurred again, I've been keeping an eye on it.

Planned implementations for version 2:
1. Deck renewal in case the game runs out of cards.
2. Make sure that, upon picking Choose Color or Draw Four, the bot only chooses a color that it has on hand.
3. "UNO!" call.
4. Card stacking.
